# Vitrine Imô Cosméticos

- `index.html`: vitrine das clientes (o link que você divulga).
- `painel.html`: cadastro dos produtos (com login).
- `gestao.html`: estoque, vendas, financeiro, preços, tráfego e notas fiscais (com login).
- `config.js`: endereço e chave do Supabase (preencha antes de enviar ao GitHub).

O banco de dados é criado pelo arquivo `banco.sql` (fica fora desta pasta e vai no Supabase, não no GitHub).
O passo a passo completo está no guia "Como colocar a Vitrine Imô no ar".
